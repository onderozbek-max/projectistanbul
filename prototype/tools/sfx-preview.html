Sound audition

Click Enable audio once (browsers need a user gesture). Every cue is synthesized in code and rendered on first use, so the first press of a cue can take a few milliseconds longer. 3x plays three variants in a row to hear the variety. Loudness is normalised per cue (loudest 50 ms RMS), so judge balance between cues, not single hits.
