Sound audition

Click Enable audio once (browsers need a user gesture). Every cue is synthesized in code (no samples, no downloads) and rendered on first use, so the first press of a cue can take a few milliseconds longer. 3x plays three variants in a row; the variant stepper picks one (cycle = random round-robin, as in the game). Loudness is set per cue (loudest 50 ms RMS, the design level), so judge balance between cues, not single hits. Listen with headphones or a phone speaker at game volume.
