# World art: run order

Generated by `node prototype/tools/gen-art-prompts-world.js`; change the generator and run it again rather than editing this file.

Total: 340 images (ground 91, props 141, facades 40, vehicles 9, weapons 52, pickups and effects 7). At about 3 minutes per image that is about 17.0 hours of generation, before your review.

## How to run one image

1. Open the prompt file and start a new chat in the "Istanbul Art" Project.
2. Attach the files under "Attach these files to the message", in the order listed.
3. Paste the block under "Paste this into ChatGPT" and send it.
4. Save the image at the path in the file header (art/commission/in/<batch>/<file>.png).
5. Tick the "Accept the image only if" list. If one item fails, send the matching line under "If it fails" in the same chat.
