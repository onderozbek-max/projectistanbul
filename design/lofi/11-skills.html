11 Street Tree

Specs: skill-tree.md (proposed, D-059) · attributes.md · game-design.md 8.1 · business-plan.md 5.1

  1. Replaces the retired Survival Skills tree (D-044). Six branches, one per attribute, in two pages: Fight (Strength, Aggression, Grit) and Street (Pace, Intelligence, Charm). Four nodes per branch.
  2. Rank is the lock, Street Cred is the key. A node needs a minimum attribute rank (1, 2, 4, 6 in Ch1) and costs 1 to 4 Street Cred. The branch header shows the current rank. A node shows the lock and the cost in text, never color only.
  3. Node states: learned (filled), available (outline), locked (dimmed, rank too low). Each node has one rank, so no pips.
  4. Bond page (third tab) is locked until Kaan joins at L20 (D-045). It lists companion perks that are earned by the bond meter, with no cost. Mila and Ada appear as locked teasers.
  5. One free respec per chapter, never sold. No store link, offer or timer on this screen.
  6. The primary button reads Learn with the cost when a node is available, and Learned (disabled) when owned. Node names are final (EN and TR, `reviews/PERK-TEXT-R1-T5.md`). Shockwave is locked here because Strength 3 is under its gate of 4.
  7. Touch targets stay 48 dp or larger. Reduced-motion: no node pulse.
